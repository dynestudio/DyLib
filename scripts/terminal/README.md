Automatically install dy Install Libs from terminal:

Windows:
```powershell
irm https://raw.githubusercontent.com/cdordelly/dyLib/dev/scripts/terminal/install_dy_install_libs.ps1 | iex
```

Linux/macOS:
```bash
curl -fsSL https://raw.githubusercontent.com/cdordelly/dyLib/dev/scripts/terminal/install_dy_install_libs.sh | bash
```
